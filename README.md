# Gator Textbook Exchange
Helps UF students find textbooks in the correct edtion at a fair price.

## Track
Marketplace / Consumer

## Problem
Students unaware of better prices or buying the wrong edition due to scattered and unranked listings.

## Planned features
- Looking up listings by course, edition, and max or lowest price
- Ranked results with a "why this ranked here" explanation
- etc...

Python, FastAPI, HTML
